# backend-next

This directory contains a Next.js-based backend project.

## Run locally

1. Install dependencies:
   ```powershell
   cd backend-next
   npm install
   ```
2. Run dev server:
   ```powershell
   npm run dev
   ```

The backend is available by default at `http://localhost:3000`.

## API routes

- `GET /api/hello`
- `GET /api/users`

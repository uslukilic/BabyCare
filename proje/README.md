# Proje

Bu klasör proje yapısını içerir.

Klasörler:

- `frontend/` — Vite React uygulaması
- `backend/` — Next.js uygulaması

Hızlı başlatma:

1. Frontend

```powershell
cd proje/frontend
npm install
npm run dev
```

2. Backend

```powershell
cd proje/backend
npm install
npm run dev
```

Not: Windows PowerShell kullanıyorsanız `npm run dev` komutlarını ayrı terminallerde çalıştırın.
